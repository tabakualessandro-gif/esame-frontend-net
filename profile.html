Il progetto

Applicazione web ispirata a Netflix, sviluppata come progetto d'esame per il corso di Frontend. Consente di navigare film e serie TV in tendenza, al cinema o in onda, attingendo in tempo reale alle API pubbliche di The Movie Database (TMDB). Il sito è strutturato come applicazione multi-pagina con HTML, CSS vanilla e JavaScript puro, senza l’utilizzo di framework o librerie esterne.
